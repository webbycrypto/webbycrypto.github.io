Todo App - FastAPI

Build a todo API as a standalone backend service with full REST endpoints, auto-generated docs, and an HTML frontend. Also shows how FastAPI acts as a middleman - calling external APIs and returning the results to your frontend.

1

Before You Start

Four concepts will make this guide much easier to follow. Virtual environments keep your project's packages isolated - activate one before installing anything, and you will see (venv) in your prompt. HTTP is the protocol every browser and app uses to talk to servers: GET retrieves data without changing anything, POST creates, PUT updates, DELETE removes. A REST API is a server that speaks HTTP and returns structured data instead of HTML - any client (browser, mobile app, Python script) can use it. JSON is the data format APIs use: it looks like {"title": "Buy milk", "done": false} and both Python and JavaScript understand it natively. When your HTML page sends a new todo to FastAPI it sends JSON in the request body, and FastAPI sends JSON back. SQLite stores everything in a single file (todos.db) with no installation required - perfect for learning.

bash 
# Create a virtual environment in your project folder
python -m venv venv

# Activate it - run this every time you open a new terminal
venv\Scripts\activate        # Windows
source venv/bin/activate      # macOS / Linux

# Your prompt will show (venv) when it is active.
# Install dependencies:
pip install fastapi uvicorn sqlalchemy aiosqlite httpx

# Or install offline if you have already downloaded the bundle:
pyoffline install --bundle fastapi

# Start the development server (auto-reloads on file changes):
uvicorn main:app --reload
# Then open: http://localhost:8000/docs

Project Structure

This app separates the backend (FastAPI) from the frontend (plain HTML files served as static files). The frontend talks to the backend using JavaScript fetch() calls - the two sides are completely independent, which is the key idea behind an API-as-a-service architecture. This means you could replace the HTML frontend with a mobile app, a React app, or a command-line tool without changing a single line of backend code. Uvicorn is the server that runs the FastAPI app - it is fast, asynchronous, and handles many requests at the same time. The static/ folder holds the HTML pages; FastAPI serves them directly so you do not need a separate web server for development.

text 
todo-fastapi/
  main.py           ← FastAPI app: todos + external API proxy
  database.py       ← SQLAlchemy connection
  models.py         ← SQLAlchemy models
  schemas.py        ← Pydantic request/response shapes
  static/
    index.html      ← frontend: todo list UI
    proxy.html      ← frontend: external API demo

Database, Model & Schemas

This layer has two distinct parts that work together. The database.py and models.py files handle storage - they define how data is saved and retrieved. The schemas.py file handles the API contract - it defines exactly what shape of data the API accepts and what it returns. Keeping models and schemas separate is important: your database model might have a password column you never want to expose, while your response schema only includes safe fields. Pydantic validates incoming data against the schema automatically - if a request sends a number where a string is expected, FastAPI rejects it with a clear error message before your code ever runs. The server_default=func.now() on created_at means the database itself sets the timestamp when a row is inserted, which is more reliable than setting it in Python (no clock skew issues across servers).

python 
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, DeclarativeBase

DATABASE_URL = "sqlite:///./todos.db"

# check_same_thread=False is required for SQLite when used with FastAPI.
# SQLite's default behaviour only allows the thread that created the connection
# to use it - but FastAPI may serve a request on a different thread.
engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})

# autocommit=False means changes are not written until you call db.commit().
# autoflush=False means SQLAlchemy doesn't automatically sync pending changes
# to the database before every query - giving you more explicit control.
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

class Base(DeclarativeBase):
    pass

# get_db() is used as a FastAPI dependency.
# 'yield' turns it into a context manager: the code before yield runs before
# the route, and the code after (db.close()) runs after - even if an error occurs.
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
python 
from sqlalchemy import Column, Integer, String, Boolean, DateTime
from sqlalchemy.sql import func
from database import Base

class Todo(Base):
    __tablename__ = "todos"
    id         = Column(Integer, primary_key=True, index=True)
    title      = Column(String(200), nullable=False)   # database rejects rows with no title
    done       = Column(Boolean, default=False)         # new todos start incomplete
    # server_default=func.now() sets the timestamp in the database engine itself,
    # not in Python - more accurate than datetime.utcnow when running multiple servers.
    created_at = Column(DateTime(timezone=True), server_default=func.now())
python 
from pydantic import BaseModel
from datetime import datetime

# TodoCreate defines what the API expects in the request body when creating a todo.
# FastAPI reads this class and automatically validates the incoming JSON.
class TodoCreate(BaseModel):
    title: str   # required - FastAPI returns 422 Unprocessable Entity if it's missing

# TodoUpdate defines what the API expects when marking a todo done or undone.
class TodoUpdate(BaseModel):
    done: bool   # required - must be true or false

# TodoOut defines what the API sends back in responses.
# It never includes internal fields the caller shouldn't see.
class TodoOut(BaseModel):
    id: int
    title: str
    done: bool
    created_at: datetime
    # from_attributes=True tells Pydantic it can read values from SQLAlchemy
    # model instances directly, not just from plain dicts.
    model_config = {"from_attributes": True}

REST API Endpoints

REST is a convention for designing APIs around resources (like todos) using the HTTP methods your browser already understands. GET retrieves data without changing anything; POST creates a new record; PUT replaces or updates a record; DELETE removes it. Using the right method matters because clients (browsers, apps, other services) use it to decide how to cache, retry, or log requests. The response status code also communicates the outcome - 200 OK means success, 201 Created means a new record was made, 204 No Content means the action succeeded but there is nothing to return (used after DELETE). FastAPI infers the correct response format and status from your type annotations and the response_model parameter. After starting the server, visit http://localhost:8000/docs to see all five endpoints listed and to send real test requests directly from the browser - no extra tool needed.

python 
from fastapi import FastAPI, Depends, HTTPException
from fastapi.staticfiles import StaticFiles
from sqlalchemy.orm import Session
from database import engine, get_db
import models, schemas

models.Base.metadata.create_all(bind=engine)

app = FastAPI(title="Todo API", description="A simple todo backend service")
app.mount("/static", StaticFiles(directory="static"), name="static")

# GET /todos - return all todos, newest first
@app.get("/todos", response_model=list[schemas.TodoOut])
def list_todos(db: Session = Depends(get_db)):
    return db.query(models.Todo).order_by(models.Todo.created_at.desc()).all()

# GET /todos/{id} - return one todo
@app.get("/todos/{todo_id}", response_model=schemas.TodoOut)
def get_todo(todo_id: int, db: Session = Depends(get_db)):
    todo = db.query(models.Todo).filter(models.Todo.id == todo_id).first()
    if not todo:
        raise HTTPException(status_code=404, detail="Todo not found")
    return todo

# POST /todos - create a new todo
@app.post("/todos", response_model=schemas.TodoOut, status_code=201)
def create_todo(data: schemas.TodoCreate, db: Session = Depends(get_db)):
    todo = models.Todo(title=data.title)
    db.add(todo)
    db.commit()
    db.refresh(todo)
    return todo

# PUT /todos/{id} - update done status
@app.put("/todos/{todo_id}", response_model=schemas.TodoOut)
def update_todo(todo_id: int, data: schemas.TodoUpdate, db: Session = Depends(get_db)):
    todo = db.query(models.Todo).filter(models.Todo.id == todo_id).first()
    if not todo:
        raise HTTPException(status_code=404, detail="Todo not found")
    todo.done = data.done
    db.commit()
    db.refresh(todo)
    return todo

# DELETE /todos/{id} - remove a todo
@app.delete("/todos/{todo_id}", status_code=204)
def delete_todo(todo_id: int, db: Session = Depends(get_db)):
    todo = db.query(models.Todo).filter(models.Todo.id == todo_id).first()
    if not todo:
        raise HTTPException(status_code=404, detail="Todo not found")
    db.delete(todo)
    db.commit()

Auto-Generated API Docs

FastAPI reads your Python type annotations and generates interactive API documentation automatically - you write no documentation code yourself. The /docs URL opens Swagger UI, a web interface where you can expand each endpoint, fill in values, click Execute, and see the real response from your running server. This is extremely useful during development: you can test your entire API without writing a frontend first. The /redoc URL is a cleaner read-only version suited for sharing with other developers or clients. The /openapi.json URL returns the raw machine-readable schema - other tools (like code generators and API testing suites) use this to understand your API automatically. Any time you add or change an endpoint, the docs update instantly with no extra steps.

python 
# FastAPI generates docs from your code automatically.
# You can customise the title, description, and version:

app = FastAPI(
    title="Todo API",
    description="A standalone todo backend. Consumes this from any frontend or mobile app.",
    version="1.0.0",
    docs_url="/docs",      # Swagger UI - interactive, lets you send real requests
    redoc_url="/redoc",    # ReDoc - cleaner read-only documentation
)

# Once running, visit:
#   http://localhost:8000/docs   ← try every endpoint in the browser
#   http://localhost:8000/redoc  ← share this with other developers
#   http://localhost:8000/openapi.json ← raw schema, used by code generators

HTML Frontend Consuming the API

The frontend is a plain HTML page that communicates with the FastAPI backend entirely through fetch() - a built-in browser function for making HTTP requests. The page never touches the database or imports any Python code; it only sends requests to the API and renders whatever the API sends back. async/await is JavaScript's way of waiting for something to finish (like a network request) without freezing the rest of the page - async marks a function as one that can pause, and await means 'wait here until this finishes before continuing'. The Content-Type: application/json header tells the server that the body of your request is JSON - FastAPI requires this when you POST data. After every mutation (add, toggle, delete) we call loadTodos() again to re-fetch the latest list from the server, which keeps the page in sync with the database without a full page refresh.

    // The base URL of the FastAPI backend
    const API = "http://localhost:8000";

    // Load and display all todos when the page opens
    async function loadTodos() {
      const res   = await fetch(API + "/todos");   // GET /todos
      const todos = await res.json();              // parse the JSON array

      const list = document.getElementById("list");
      list.innerHTML = "";                          // clear old items

      todos.forEach(todo => {
        const div = document.createElement("div");
        div.className = "todo-item" + (todo.done ? " done" : "");
        div.id = "todo-" + todo.id;
        div.innerHTML = `
          <class="hl-tag">span>${todo.title}</class="hl-tag">span>
          <class="hl-tag">button class="toggle" onclick="toggleTodo(${todo.id}, ${todo.done})">
            ${todo.done ? "Undo" : "Done"}
          </class="hl-tag">button>
          <class="hl-tag">button class="delete" onclick="deleteTodo(${todo.id})">Delete</class="hl-tag">button>`;
        list.appendChild(div);
      });
    }

    // Add a new todo by POSTing to the API
    async function addTodo() {
      const input = document.getElementById("newTitle");
      const title = input.value.trim();
      if (!title) return;                           // do nothing if input is empty

      await fetch(API + "/todos", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ title })             // send title as JSON
      });

      input.value = "";                             // clear the input field
      loadTodos();                                  // refresh the list
    }

    // Toggle done state by sending PUT with the flipped value
    async function toggleTodo(id, currentDone) {
      await fetch(API + "/todos/" + id, {
        method: "PUT",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ done: !currentDone })  // flip the done flag
      });
      loadTodos();
    }

    // Delete a todo by sending a DELETE request
    async function deleteTodo(id) {
      await fetch(API + "/todos/" + id, { method: "DELETE" });
      loadTodos();
    }

    loadTodos();  // run as soon as the page loads
  </class="hl-tag">script>
</class="hl-tag">body>

FastAPI as a Middleman - Calling External APIs

A proxy endpoint sits between your frontend and a third-party API. The frontend calls your server, your server calls the external API, and your server returns the result - the external URL and any API keys never leave your server. This pattern is useful in several situations: hiding credentials (API keys must never appear in browser code), reshaping data (the external API returns 20 fields but you only need 3), adding caching (store responses so you do not hit rate limits), or combining multiple external calls into one. httpx is an async HTTP client - like the popular requests library but designed to work inside async functions like FastAPI endpoints. asyncio.gather() fires multiple HTTP requests at the same time and waits for all of them to complete, which is much faster than sending them one after the other. HTTP 502 Bad Gateway is the correct status code to return when your server called another server and that server failed - it tells the caller 'it's not your request that's broken, the upstream service is'.

python 
import httpx  # async HTTP client - like requests but works with FastAPI's async

# This endpoint calls JSONPlaceholder (a free public test API) on behalf of the frontend.
# The frontend sends one request to /proxy/todos/{id} and gets back a clean response.
# The external API URL and any secret keys stay on the server - never exposed to the browser.

EXTERNAL_API = "https://jsonplaceholder.typicode.com"

@app.get("/proxy/sample-todo/{item_id}")
async def proxy_external_todo(item_id: int):
    # Use async with so the HTTP client is properly cleaned up after the request
    async with httpx.AsyncClient() as client:
        response = await client.get(f"{EXTERNAL_API}/todos/{item_id}")

    if response.status_code != 200:
        raise HTTPException(status_code=502, detail="External API failed")

    raw = response.json()

    # Transform the external API's shape into your own clean format
    # The frontend gets your format - it never sees the raw external response
    return {
        "source":    "jsonplaceholder",
        "id":        raw["id"],
        "title":     raw["title"],
        "completed": raw["completed"],
    }

# You can also combine multiple external API calls into one response:
@app.get("/proxy/summary")
async def proxy_summary():
    async with httpx.AsyncClient() as client:
        # Fire both requests at the same time using asyncio
        import asyncio
        todo_res, user_res = await asyncio.gather(
            client.get(f"{EXTERNAL_API}/todos/1"),
            client.get(f"{EXTERNAL_API}/users/1"),
        )
    return {
        "todo": todo_res.json(),
        "user": user_res.json(),
    }
