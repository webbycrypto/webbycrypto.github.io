Nginx Reverse Proxy

Put Nginx in front of uvicorn. Nginx listens on port 80 (HTTP) and forwards requests to uvicorn running on port 8000. This gives you a standard URL, better performance for static files, and a foundation for HTTPS.

1

What Nginx Does

Nginx sits between the internet and uvicorn. Browsers connect to Nginx on port 80 (or 443 for HTTPS). Nginx forwards the request to uvicorn on localhost:8000, gets the response, and sends it back. uvicorn never talks directly to the outside world.

text
Browser → port 80 → Nginx → localhost:8000 → uvicorn → FastAPI

Without Nginx:  http://yoursite.com:8000  (ugly, non-standard)
With Nginx:     http://yoursite.com       (standard port 80)
With Nginx+SSL: https://yoursite.com      (secure, professional)

Nginx also:
  - Serves static files directly (faster than Python)
  - Handles SSL/TLS termination (with Certbot)
  - Can rate-limit, add headers, redirect URLs
  - Can proxy to multiple backends (load balancing)
2

Install Nginx

bash
sudo apt install -y nginx

# Start and enable Nginx (so it starts on boot)
sudo systemctl enable nginx
sudo systemctl start nginx

# Test it's working
curl http://localhost
# Should return the default Nginx welcome page HTML

# Or visit http://YOUR_SERVER_IP in your browser
# You should see "Welcome to nginx!"

Write the Site Config

Each website gets its own config file in /etc/nginx/sites-available/. The core directive is proxy_pass — it tells Nginx where to forward requests.

nginx — /etc/nginx/sites-available/myapp
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location / {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        # These headers tell FastAPI the original request info
        # without them, request.client.host would show 127.0.0.1
    }
}
nginx — IP only (testing)
server {
    listen 80 default_server;
    server_name _;     # matches any hostname / IP

    location / {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host            $host;
        proxy_set_header   X-Real-IP       $remote_addr;
    }
}

# Use this if you don't have a domain yet
# Access via: http://YOUR_SERVER_IP
Create the file: sudo nano /etc/nginx/sites-available/myapp — paste the config, save with Ctrl+O, exit with Ctrl+X.
4

Enable the Site

Nginx reads from sites-enabled/ — symlink your config there, remove the default, test, and reload.

bash
# Create a symlink from sites-enabled to sites-available
sudo ln -s /etc/nginx/sites-available/myapp /etc/nginx/sites-enabled/

# Remove the default site (optional but cleaner)
sudo rm /etc/nginx/sites-enabled/default

# Test the config syntax — always do this before reloading
sudo nginx -t
# Should say: nginx: configuration file ... syntax is ok

# Reload Nginx (graceful — no dropped connections)
sudo systemctl reload nginx

# Make sure uvicorn is running on port 8000, then test:
curl http://localhost          # should return your FastAPI response
curl http://YOUR_SERVER_IP     # same from outside

Serve Static Files via Nginx

Nginx can serve CSS, JS, and images directly from disk — much faster than routing them through Python. Add a location /static block that points to your app's static folder.

nginx
server {
    listen 80;
    server_name yourdomain.com;

    # Serve static files directly — bypass Python entirely
    location /static {
        alias /home/deploy/apps/yourapp/static;
        expires 30d;              # tell browsers to cache for 30 days
        add_header Cache-Control "public";
    }

    # Everything else goes to FastAPI
    location / {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host            $host;
        proxy_set_header   X-Real-IP       $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}

Common Errors

text
502 Bad Gateway
  Nginx is running but can't reach uvicorn.
  Check: is uvicorn actually running on port 8000?
    sudo ss -tlnp | grep 8000
  Check Nginx error log:
    sudo tail -f /var/log/nginx/error.log

403 Forbidden (for /static)
  Nginx can't read the static files.
  Fix: the www-data user needs read access.
    sudo chmod -R o+r /home/deploy/apps/yourapp/static
  Or check the path is correct in the alias directive.

404 Not Found
  Nginx is proxying to FastAPI but the route doesn't exist.
  Check your FastAPI routes, not Nginx.

"nginx: configuration file syntax error"
  You have a typo in the config.
  sudo nginx -t  shows the exact line.
  Common: missing semicolons, unclosed braces.
