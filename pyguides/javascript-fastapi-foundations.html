JavaScript & FastAPI Foundations

Requires completing the FastAPI Learning Series first. Learn JavaScript fundamentals, async functions, and the fetch API to communicate with FastAPI backends.

1

Variables and Data Types

JavaScript uses let and const to declare variables. let can be reassigned while const cannot change after creation. The basic data types are string, number, boolean, and object.

javascript 
let name = "Alice";     // can be reassigned
const age = 25;      // cannot change after creation

name = "Bob";           // this works
age = 26;              // Error: const cannot be reassigned
javascript 
let text = "hello";        // string: text in quotes
let count = 42;            // number: integer or decimal
let isActive = true;       // boolean: true or false
let data = { id: 1, name: "Item" }; // object: key-value pairs
2

Functions and Arrow Functions

Functions are reusable blocks of code. The arrow function syntax => is modern and concise. Both take inputs called parameters and return an output.

javascript 
function greet(name) {
  return "Hello, " + name;
}

greet("Alice");  // "Hello, Alice"
javascript 
const greet = (name) => {
  return "Hello, " + name;
};

// or shorter, one line:
const greet = (name) => "Hello, " + name;

greet("Alice");  // "Hello, Alice"
3

Event Handling and DOM Basics

The DOM is the page structure. JavaScript can listen for user actions like button clicks using event listeners. When the user clicks, a function runs.

html 
<button id="myButton">Click me</button>
<p id="message"></p>
javascript 
const button = document.getElementById("myButton");
const message = document.getElementById("message");

button.addEventListener("click", () => {
  message.textContent = "Button was clicked";
});
4

Callbacks and Async Code

Synchronous code runs line by line, waiting for each line to finish. Asynchronous code starts a task and moves on without waiting. Callbacks are functions passed to other functions to run later.

javascript 
console.log("Step 1");
console.log("Step 2");  // waits for step 1 to finish
console.log("Step 3");  // waits for step 2 to finish

// Output: Step 1, Step 2, Step 3 (in order, one after another)
javascript 
console.log("Step 1");
setTimeout(() => {
  console.log("Step 2");  // runs after 1 second
}, 1000);
console.log("Step 3");  // doesn't wait for step 2

// Output: Step 1, Step 3, Step 2
5

Introduction to Fetch

The fetch API is JavaScript's way to send HTTP requests to a server. It takes a URL and returns a promise, which is a placeholder for a value that will arrive later.

javascript 
const response = await fetch("http://localhost:8001/api/todos");
const data = await response.json();
console.log(data);  // [{ id: 1, title: "Buy milk" }, ...]
javascript 
const response = await fetch("http://localhost:8001/api/todos", {
  method: "POST",           // HTTP method for creating
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ title: "Buy milk" })
});
const data = await response.json();
console.log(data);  // { id: 1, title: "Buy milk" }
6

async/await Syntax

The async keyword marks a function that uses await. await pauses until the promise resolves. This makes async code look like synchronous code.

javascript 
async function fetchTodos() {
  // this function is async, so we can use await
  const response = await fetch("/api/todos");
  const todos = await response.json();
  return todos;
}
javascript 
const fetchTodos = async () => {
  const response = await fetch("/api/todos");
  const todos = await response.json();
  return todos;
};

fetchTodos().then(todos => console.log(todos));
7

JSON Parsing and Serialization

FastAPI sends and receives JSON. JavaScript uses JSON.parse() to convert text to objects and JSON.stringify() to convert objects to text.

javascript 
// Convert JSON text to JavaScript object
const jsonText = '{ "id": 1, "title": "Buy milk" }';
const obj = JSON.parse(jsonText);
console.log(obj.title);  // "Buy milk"
javascript 
// Convert JavaScript object to JSON text
const obj = { id: 1, title: "Buy milk" };
const jsonText = JSON.stringify(obj);
console.log(jsonText);  // '{"id":1,"title":"Buy milk"}'
8

HTTP Status Codes and Error Handling

Every HTTP response has a status code. 200-299 means success. 400 means bad request. 404 means not found. 500 means server error. Always check the status before using the data.

javascript 
const response = await fetch("/api/todos/999");
if (response.status === 200) {
  const todo = await response.json();
  console.log(todo);
} else if (response.status === 404) {
  console.log("Todo not found");
} else {
  console.log("Server error");
}
javascript 
try {
  const response = await fetch("/api/todos");
  if (!response.ok) {  // ok is true for 200-299
    throw new Error("Network error");
  }
  const todos = await response.json();
  console.log(todos);
} catch (err) {
  console.log("Error:", err.message);
}

Understanding FastAPI Routes and Endpoints

FastAPI uses decorators like @app.get() and @app.post() to define endpoints. The URL path like /api/todos is where JavaScript sends requests. JSON-only endpoints are under /api/.

python 
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Todo(BaseModel):
    title: str

@app.get("/api/todos")  // responds to GET requests
def list_todos():
    return [{ "id": 1, "title": "Buy milk" }]

@app.post("/api/todos")  // responds to POST requests
def create_todo(todo: Todo):
    return { "id": 1, "title": todo.title }
javascript 
// GET request → @app.get("/api/todos")
const todos = await fetch("/api/todos").then(r => r.json());

// POST request → @app.post("/api/todos")
const newTodo = await fetch("/api/todos", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ title: "Buy milk" })
}).then(r => r.json());

Connecting a Form to FastAPI

Combine all the concepts: listen for form submission, get input values, send a POST request, and update the page with the response.

html 
<form id="todoForm">
  <input type="text" id="titleInput" placeholder="Enter title" />
  <button type="submit">Add Todo</button>
</form>
<ul id="todoList"></ul>
javascript 
const form = document.getElementById("todoForm");
const titleInput = document.getElementById("titleInput");
const todoList = document.getElementById("todoList");

form.addEventListener("submit", async (e) => {
  e.preventDefault();  // prevent page reload

  const title = titleInput.value;

  try {
    const response = await fetch("/api/todos", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ title: title })
    });
    if (!response.ok) throw new Error("Request failed");

    const newTodo = await response.json();

    // Add item to the list
    const li = document.createElement("li");
    li.textContent = newTodo.title;
    todoList.appendChild(li);

    titleInput.value = "";  // clear the input
  } catch (err) {
    console.error("Error:", err.message);
  }
});
