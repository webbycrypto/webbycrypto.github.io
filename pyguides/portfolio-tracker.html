Multi-Source Financial Portfolio Tracker

Build a live portfolio dashboard that fetches stock prices from Alpha Vantage and crypto prices from CoinGecko concurrently, calculates net worth and P&L, and displays them in a Jinja2 dashboard with a JSON price-refresh button.

1

What We're Building

This tracker stores your stock and crypto holdings in SQLite. When you load the dashboard, FastAPI fetches live prices from two free external APIs at the same time, calculates your current portfolio value and profit/loss, and renders the results in a Jinja2 HTML page. You also get a "Refresh prices" button that updates just the numbers without reloading the whole page.

text
Browser → GET /dashboard
           ↓
FastAPI reads holdings from SQLite
           ↓
asyncio.gather() fetches BOTH at once:
  ├── Alpha Vantage → stock prices (AAPL, MSFT)
  └── CoinGecko     → crypto prices (bitcoin, ethereum)

Database Models

Three models cover the data you need. Holding stores what you own, how many, and what you paid. PriceCache stores the last fetched price with a timestamp so you do not hit the API on every single request.

python
from sqlalchemy import Column, Integer, String, Float, DateTime
from sqlalchemy.ext.declarative import declarative_base
from datetime import datetime

Base = declarative_base()

class Holding(Base):
    __tablename__ = "holdings"

    id            = Column(Integer, primary_key=True)
    symbol        = Column(String)          # → "AAPL", "bitcoin"
    name          = Column(String)          # → "Apple Inc.", "Bitcoin"
    quantity      = Column(Float)           # → number of shares or coins
    avg_buy_price = Column(Float)           # → average cost per unit in USD
    asset_type    = Column(String)          # → "stock" or "crypto"


class PriceCache(Base):
    __tablename__ = "price_cache"

    id         = Column(Integer, primary_key=True)
    symbol     = Column(String, unique=True)  # → one row per symbol
    price      = Column(Float)
    fetched_at = Column(DateTime, default=datetime.utcnow)

# A Portfolio model (with user_id FK) can be added later for multi-user support.
# For now a single shared portfolio is stored in the holdings table.

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

def init_db():
    Base.metadata.create_all(bind=engine)  # → creates tables if they don't exist

Seed Holdings

The seed data creates a realistic sample portfolio so the dashboard shows real numbers right away. Holdings include two stocks and two crypto assets with typical quantities and approximate buy prices from 2023.

Fetch Crypto Prices

CoinGecko's simple price endpoint returns current prices for multiple coins in a single request. You pass a comma-separated list of coin IDs and the currency. No API key is required, making it the easiest external API to start with.

python
import httpx

async def fetch_crypto_prices(symbols: list[str]) -> dict[str, float]:
    """Returns {symbol: price} for each symbol. Returns {} on error."""
    ids = ",".join(symbols)                              # → "bitcoin,ethereum"
    url = "https://api.coingecko.com/api/v3/simple/price"
    params = {"ids": ids, "vs_currencies": "usd"}
    try:
        async with httpx.AsyncClient(timeout=10) as client:
            resp = await client.get(url, params=params)
            resp.raise_for_status()
            data = resp.json()
            # data["bitcoin"]["usd"] → float price
            return {sym: data[sym]["usd"] for sym in symbols if sym in data}
    except Exception:
        return {}  # → caller uses cached prices as fallback

# Symbol note: store the CoinGecko coin ID in Holding.symbol,
# not the ticker. "bitcoin" works; "BTC" does not.
# Full list: https://api.coingecko.com/api/v3/coins/list

Fetch Stock Prices

Alpha Vantage's GLOBAL_QUOTE endpoint returns the latest price for a single stock symbol. The free tier allows 25 requests per day, so the PriceCache table stores the last fetched price. If the cached price is less than 15 minutes old, you return it instead of hitting the API again.

python
import os, httpx
from datetime import datetime, timedelta
from sqlalchemy.orm import Session
from .models import PriceCache

ALPHA_VANTAGE_KEY = os.getenv("ALPHA_VANTAGE_API_KEY", "")
CACHE_TTL = timedelta(minutes=15)          # → reuse price if under 15 min old

async def fetch_stock_price(symbol: str, db: Session) -> float:
    # Step 1: check the cache
    cached = db.query(PriceCache).filter(PriceCache.symbol == symbol).first()
    if cached and (datetime.utcnow() - cached.fetched_at) < CACHE_TTL:
        return cached.price         # → fresh enough, skip the API call

    # Step 2: fetch from Alpha Vantage
    url = "https://www.alphavantage.co/query"
    params = {
        "function": "GLOBAL_QUOTE",
        "symbol":   symbol,
        "apikey":   ALPHA_VANTAGE_KEY,
    }
    async with httpx.AsyncClient(timeout=10) as client:
        resp = await client.get(url, params=params)
        resp.raise_for_status()
        data = resp.json()

    price = float(data["Global Quote"]["05. price"])  # → parse price string

    # Step 3: update or create the cache entry
    if cached:
        cached.price      = price
        cached.fetched_at = datetime.utcnow()
    else:
        db.add(PriceCache(symbol=symbol, price=price, fetched_at=datetime.utcnow()))
    db.commit()

    return price

Concurrent Fetching

Fetching prices one at a time would be slow. asyncio.gather() runs all the coroutines at the same time and waits for all of them to finish, reducing the total wait time to roughly the slowest single request. Each task is wrapped in a try/except so one API failure does not crash the whole dashboard.

python
import asyncio
import logging
from .price_service import fetch_crypto_prices, fetch_stock_price

logger = logging.getLogger(__name__)

async def fetch_all_prices(holdings, db) -> dict[str, float]:
    # Separate holdings by asset type
    crypto_symbols = [h.symbol for h in holdings if h.asset_type == "crypto"]
    stock_symbols  = [h.symbol for h in holdings if h.asset_type == "stock"]

    # Build one coroutine per source (CoinGecko batches all crypto in one call)
    tasks = [fetch_crypto_prices(crypto_symbols)]
    tasks += [fetch_stock_price(sym, db) for sym in stock_symbols]

    results = await asyncio.gather(*tasks, return_exceptions=True)

    prices = {}

    # First result is from CoinGecko → a dict of {symbol: price}
    crypto_result = results[0]
    if isinstance(crypto_result, dict):
        prices.update(crypto_result)
    else:
        logger.warning("CoinGecko fetch failed: %s", crypto_result)

    # Remaining results are individual stock prices
    for sym, result in zip(stock_symbols, results[1:]):
        if isinstance(result, Exception):
            logger.warning("Stock fetch failed for %s: %s", sym, result)
            # Fallback: use the last cached price if available
            cached = db.query(PriceCache).filter(PriceCache.symbol == sym).first()
            if cached:
                prices[sym] = cached.price
        else:
            prices[sym] = result         # → float price

    return prices
text
Sequential (slow):
  fetch AAPL   → 0.4s
  fetch MSFT   → 0.4s
  fetch BTC    → 0.3s
  fetch ETH    → 0.3s
  Total:         1.4s

asyncio.gather() (fast):
  all 4 run at the same time
  Total:         ~0.4s  (limited by the slowest)

The speedup grows with the number of holdings.
10 holdings in sequence could take 4+ seconds;
with gather() it still finishes in about 0.5s.

Portfolio Calculations

Once you have live prices, calculating the portfolio metrics is straightforward arithmetic. For each holding you multiply the quantity by the current price to get the current value, then subtract the cost basis (quantity times average buy price) to get the profit or loss.

python
def calculate_metrics(holdings, prices: dict) -> list:
    rows = []
    for h in holdings:
        live_price    = prices.get(h.symbol, 0)
        current_value = h.quantity * live_price            # → what it's worth now
        cost_basis    = h.quantity * h.avg_buy_price       # → what you paid
        pnl           = current_value - cost_basis         # → profit or loss in USD
        pnl_pct       = (pnl / cost_basis * 100) if cost_basis else 0

        rows.append({
            "symbol":        h.symbol,
            "name":          h.name,
            "quantity":      h.quantity,
            "avg_buy":       h.avg_buy_price,
            "live_price":    live_price,
            "current_value": current_value,
            "pnl":           pnl,
            "pnl_pct":       pnl_pct,
            "asset_type":    h.asset_type,
        })
    return rows

Dashboard Endpoint

The dashboard route ties everything together. It loads holdings from the database, fetches all live prices concurrently, runs the calculations, and passes the results to the Jinja2 template in one TemplateResponse.

python
from fastapi import FastAPI, Depends, Request
from fastapi.templating import Jinja2Templates
from sqlalchemy.orm import Session
from .database import get_db
from .models import Holding
from .price_service import fetch_all_prices
from .calculations import calculate_metrics

templates = Jinja2Templates(directory="templates")

@app.get("/dashboard")
async def dashboard(request: Request, db: Session = Depends(get_db)):
    holdings = db.query(Holding).all()
    prices   = await fetch_all_prices(holdings, db)   # → concurrent fetch
    rows     = calculate_metrics(holdings, prices)

    total_value   = sum(r["current_value"] for r in rows)
    total_cost    = sum(h.quantity * h.avg_buy_price for h in holdings)
    total_pnl     = total_value - total_cost
    total_pnl_pct = (total_pnl / total_cost * 100) if total_cost else 0

    return templates.TemplateResponse("dashboard.html", {
        "request":       request,   # → Jinja2 requires this key
        "rows":          rows,
        "total_value":   total_value,
        "total_pnl":     total_pnl,
        "total_pnl_pct": total_pnl_pct,
    })

JSON Refresh Endpoint

The Refresh button in the template calls this endpoint. It fetches fresh prices, recalculates the metrics, and returns a JSON object keyed by symbol. The JavaScript in the template reads each value and updates the correct table cell without reloading the page.

python
@app.get("/dashboard/prices")
async def prices_json(db: Session = Depends(get_db)):
    holdings = db.query(Holding).all()
    prices   = await fetch_all_prices(holdings, db)   # → concurrent fetch
    rows     = calculate_metrics(holdings, prices)

    # Return a dict keyed by symbol so the JS can look up each cell by ID.
    return {
        row["symbol"]: {
            "live_price":    row["live_price"],
            "current_value": row["current_value"],
            "pnl":           row["pnl"],
            "pnl_pct":       row["pnl_pct"],
        }
        for row in rows
    }

What's Next

Rate limits and caching strategy. Alpha Vantage's free tier allows 25 requests per day, so the PriceCache table is essential. In production you would increase the cache TTL to 15 to 60 minutes and add a background job (see the Background Tasks guide) to refresh prices on a schedule rather than on every page load.
Adding real authentication. Right now anyone can see the portfolio. The JWT and Refresh Token guides show how to add a login page and protect the dashboard route with a Depends(get_current_user) dependency.
WebSocket live prices. For a real-time dashboard that updates automatically every few seconds without a button click, see the WebSockets guide. Replace the JSON endpoint with a WebSocket that pushes new prices from the server.
