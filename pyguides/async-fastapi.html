1

Sync vs Async Fundamentals

Synchronous code waits for each operation to finish before moving to the next. Asynchronous code starts multiple operations and doesn't wait. This matters when an operation involves network requests, file I/O, or database queries that take time.

python 
import time

def slow_task(n):
    time.sleep(2)  // blocks for 2 seconds
    return f"Task {n} done"

// This takes 6 seconds total
for i in range(3):
    result = slow_task(i)
    print(result)
python 
import asyncio

async def slow_task(n):
    await asyncio.sleep(2)  // doesn't block others
    return f"Task {n} done"

// This takes 2 seconds total (all run in parallel)
await asyncio.gather(
    slow_task(0),
    slow_task(1),
    slow_task(2)
)
Key difference: Sync blocks the entire program. Async starts tasks and moves on, so multiple operations can progress at the same time (concurrently).
2

async/await Syntax

The async keyword marks a function as asynchronous. The await keyword pauses inside an async function until the awaited operation completes, then continues. Always use await inside async functions.

python 
async def fetch_data():
    // pause here until the operation finishes
    result = await some_slow_operation()
    return result

// Call async functions with await
data = await fetch_data()
print(data)
python 
async def process():
    user = await fetch_user(1)    // wait for user
    posts = await fetch_posts(user.id)  // then fetch posts
    comments = await fetch_comments(posts[0].id)
    return {"user": user, "posts": posts, "comments": comments}

asyncio.gather() for Concurrent Execution

asyncio.gather() runs multiple async functions at the same time and waits for all of them to finish. Use it when you have independent tasks that don't depend on each other's results.

python 
import asyncio

async def main():
    // All three run at the same time
    results = await asyncio.gather(
        fetch_user(1),
        fetch_user(2),
        fetch_user(3)
    )
    return results  // list of 3 users

// Run async function from sync code
asyncio.run(main())
python 
async def safe_gather():
    results = await asyncio.gather(
        fetch_user(1),
        fetch_user(2),
        fetch_user(3),
        return_exceptions=True  // don't stop on error
    )
    // results may contain Exception objects
    for result in results:
        if isinstance(result, Exception):
            print(f"Error: {result}")
        else:
            print(f"User: {result}")

FastAPI Async Endpoints

FastAPI routes can be async or sync. Define async routes with async def. FastAPI runs async routes in a thread pool and sync routes in another, so both work without blocking the server.

python 
from fastapi import FastAPI
import httpx

app = FastAPI()

@app.get("/user/{user_id}")
async def get_user(user_id: int):
    // This endpoint is async
    async with httpx.AsyncClient() as client:
        response = await client.get(f"https://api.example.com/users/{user_id}")
    return response.json()
python 
@app.get("/dashboard/{user_id}")
async def get_dashboard(user_id: int):
    // Fetch user, posts, and comments concurrently
    async with httpx.AsyncClient() as client:
        user, posts, comments = await asyncio.gather(
            client.get(f"https://api.example.com/users/{user_id}"),
            client.get(f"https://api.example.com/users/{user_id}/posts"),
            client.get(f"https://api.example.com/users/{user_id}/comments")
        )
    return {
        "user": user.json(),
        "posts": posts.json(),
        "comments": comments.json()
    }

Blocking vs Non-Blocking I/O

Blocking calls pause the program until the operation finishes. Non-blocking calls start the operation and return immediately. Network, file, and database operations are blocking; use async versions to avoid blocking the entire server.

python 
import requests  // blocking HTTP library

@app.get("/weather")
def get_weather():
    // This blocks the entire server for ~1 second
    response = requests.get("https://api.weather.com/forecast")  // blocks!
    return response.json()

// While one user is getting weather, others must wait
python 
import httpx  // can be used async

@app.get("/weather")
async def get_weather():
    // This pauses only this request, not the server
    async with httpx.AsyncClient() as client:
        response = await client.get("https://api.weather.com/forecast")  // doesn't block!
    return response.json()

// Other users can be served while this one waits

Timeouts and Cancellation

Long-running operations can hang. Use asyncio.wait_for() to set a timeout. Use asyncio.CancelledError to handle cancellation when a request is interrupted.

python 
import asyncio

@app.get("/data")
async def get_data():
    try:
        // If this takes longer than 5 seconds, raise TimeoutError
        result = await asyncio.wait_for(fetch_remote_data(), timeout=5.0)
        return result
    except asyncio.TimeoutError:
        return {"error": "Request took too long"}
python 
@app.get("/stream")
async def stream_data():
    task = asyncio.create_task(long_running_operation())
    try:
        return await asyncio.wait_for(task, timeout=30)
    except asyncio.TimeoutError:
        task.cancel()  // stop the background task
        return {"error": "Stream cancelled"}

Concurrent Database Queries

Use async database drivers like aiosqlite for SQLite or asyncpg for PostgreSQL. They don't block the server while waiting for database responses.

python 
import aiosqlite

@app.get("/users")
async def get_users():
    async with aiosqlite.connect("db.sqlite") as db:
        cursor = await db.execute("SELECT * FROM users")
        users = await cursor.fetchall()
    return users

// Fetch user and posts concurrently
@app.get("/dashboard/{user_id}")
async def get_dashboard(user_id: int):
    async with aiosqlite.connect("db.sqlite") as db:
        user, posts = await asyncio.gather(
            db.execute_one(f"SELECT * FROM users WHERE id = {user_id}"),
            db.execute(f"SELECT * FROM posts WHERE user_id = {user_id}")
        )
    return {"user": user, "posts": posts}

Rate Limiting with Async

When calling external APIs, respect rate limits using semaphores. A semaphore ensures only N operations run at the same time, preventing API rejection.

python 
import asyncio
import httpx

// Allow only 5 concurrent requests
semaphore = asyncio.Semaphore(5)

async def fetch_with_limit(client, url):
    async with semaphore:  // wait if 5 already running
        response = await client.get(url)
        return response.json()

@app.get("/batch")
async def batch_fetch():
    urls = ["https://api.example.com/item/1", "https://api.example.com/item/2", ...]
    async with httpx.AsyncClient() as client:
        results = await asyncio.gather(*[fetch_with_limit(client, url) for url in urls])
    return results

Testing Async Code

Use pytest with pytest-asyncio to test async functions. Mark test functions with @pytest.mark.asyncio and use async def for the test.

python 
import pytest
from httpx import AsyncClient
from app import app

@pytest.mark.asyncio
async def test_get_user():
    async with AsyncClient(app=app, base_url="http://test") as client:
        response = await client.get("/user/1")
    assert response.status_code == 200
    assert response.json()["id"] == 1

@pytest.mark.asyncio
async def test_concurrent_requests():
    async with AsyncClient(app=app, base_url="http://test") as client:
        results = await asyncio.gather(
            client.get("/user/1"),
            client.get("/user/2")
        )
    assert len(results) == 2

Real-World: Financial Portfolio Tracker

Apply async patterns to fetch live stock and crypto prices concurrently. Multiple API calls run at the same time, then we calculate portfolio metrics all at once.

python 
async def get_portfolio(user_id: int):
    async with httpx.AsyncClient() as client:
        // Fetch portfolio, stock prices, and crypto prices concurrently
        portfolio, stocks, cryptos = await asyncio.gather(
            client.get(f"https://api.example.com/portfolio/{user_id}"),
            client.get("https://api.alphavantage.co/stocks"),
            client.get("https://api.coingecko.com/crypto"),
            return_exceptions=True
        )

        // Calculate net worth
        portfolio_data = portfolio.json()
        stock_prices = stocks.json()
        crypto_prices = cryptos.json()

        net_worth = 0
        for holding in portfolio_data["holdings"]:
            if holding["type"] == "stock":
                price = stock_prices[holding["symbol"]]
            else:
                price = crypto_prices[holding["symbol"]]
            net_worth += holding["amount"] * price

        return {"portfolio": portfolio_data, "net_worth": net_worth}
