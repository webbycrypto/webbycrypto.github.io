Pick one capstone spec from the chosen track and build it. Only documentation and the learner's own judgment, no tutorial. This is the self-sufficiency test, not a bonus round.

1. [ ] Pick one spec. AI track: [Docs assistant](ai/docs-assistant.md) · [Ticket triage service](ai/ticket-triage.md) · [Research agent](ai/research-agent.md). Blockchain track: [Acceptance gate](blockchain/acceptance-gate.md) (flagship) · [Token issuance backend](blockchain/token-issuance.md).

3. [ ] [Self-sufficiency rubric](rubric.md) (Day 5): score yourself honestly, then decide whether to continue into the second track (see the root README's "The second track").
