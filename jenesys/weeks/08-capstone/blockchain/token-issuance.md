# Token issuance backend

[← Back to Week 8: Capstone, no safety net](../README.md)

Build a backend service that issues and tracks a simple token on behalf of a business process (loyalty points, credits, the learner's framing), with an internal API to trigger issuance and check balances.

## Constraints

- It must be able to detect and report a mismatch between its internal ledger and actual on-chain state.

Anything not specified here (data format, exact API shape, how to structure the code) is the learner's call to make and justify, not a gap to ask about.
