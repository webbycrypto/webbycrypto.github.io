# Docs assistant

[← Back to Week 8: Capstone, no safety net](../README.md)

Build a tool that answers questions about a folder of text/markdown documents the learner provides.

## Constraints

- It must refuse to answer, rather than guess, when the documents don't contain the answer.
- Every answer must cite which document (and ideally which section) it came from.
- Interface can be a CLI or a small API, the learner's choice.

Anything not specified here (data format, exact API shape, how to structure the code) is the learner's call to make and justify, not a gap to ask about.
