# Weeks

The full curriculum, philosophy, and reasoning live in [the root README](../README.md). This folder is the working skeleton: one subfolder per week, matching that document exactly. Duration is a range (6 weeks floor, 8 weeks average, 10-12 weeks normal), not a fixed schedule. For a full, flat list of every note and brief inside each week below, see [../table-of-contents.md](../table-of-contents.md).

- [00-setup](00-setup/README.md), tools and accounts, before Day 1
- [01-foundations-i](01-foundations-i/README.md)
- [02-foundations-ii](02-foundations-ii/README.md)
- [03-foundations-consolidation](03-foundations-consolidation/README.md), ends with the Foundations checkpoint
- [04-track-exposure](04-track-exposure/README.md), ends with choosing a track
- [05-guided-build](05-guided-build/), split by track
- [06-low-scaffolding](06-low-scaffolding/), split by track
- [07-low-scaffolding-continued](07-low-scaffolding-continued/), split by track
- [08-capstone](08-capstone/), split by track, plus the self-sufficiency rubric

Weeks 5 through 7 (and the second pass through them for a learner doing both tracks) have an `ai/` and a `blockchain/` folder. Use only the one matching the track chosen at the end of Week 4.
